PakFlow

Project Overview

PakFlow is an automated, AI-driven order validation system that helps e-commerce merchants in Pakistan confirm Cash-on-Delivery (COD) orders prior to dispatch.

By integrating directly with Shopify/WooCommerce, PakFlow triggers automated conversations via WhatsApp and Voice calls to verify customer intent. This filters out invalid/accidental orders, successfully reducing RTO (Return to Origin) logistics costs by up to 35%.

System Architecture

E-commerce Webhook
Apache Kafka Event Stream
Node.js Microservices
Redis (Cache & Session Rate-Limits)
AI NLP Voice Bot & WhatsApp API

SIUT HMS

Project Overview

The Hospital Management System (HMS) developed for the Sindh Institute of Urology and Transplantation (SIUT) handles end-to-end clinical workflows for one of the largest public healthcare institutions in Karachi.

To coordinate patient volumes, we architected a system that routes OP/IP admissions, allocates diagnostic clinics, prints lab reports, and queues pharmacy items. Given the high transaction load, background tasks are delegated to queues to prevent slow patient check-outs.

System Architecture

Doctor & Patient Terminals
PHP Yii Backend Server
RabbitMQ Event Broker
Background Worker (PDF Reports & Pharmacy Queue)
Redis Caching & MySQL DB
